## friend-in-md v0.2.0

```bash
npx friend-in-md@latest <dir>
```

### New features

- **Marp slide decks** — files with `marp: true` front matter render as slides (read-only). Theme dropdown (`default` / `gaia` / `uncover` + custom themes from `.marp-themes/`), **▶ Present** fullscreen slideshow, **📝 Presenter notes** window synced across displays, and **🎞 Export PowerPoint** (`.pptx` via marp-cli, needs Chrome/Chromium).
- **Quick note popup** — small read-only popup showing markdown files flagged with `quick: true`. Folder set in Settings. Installable as a standalone app (PWA) in Chrome/Edge.
- **PDF export** — **🖨 Export PDF** prints only the note content.
- **Image viewer** — image files (png/jpg/gif/webp/svg/bmp/avif) open from the file tree; double-click an image in a note for fullscreen zoom/pan.
- **Autosave** — unlocked files save automatically ~3 s after you stop typing.
- **Colored text** — `<span style="color: …">` / `<font color="…">` render as colored text.
- **Settings panel (⚙)** — editor font, CSV size limit, fill-handle default, quick-note folder, sidebar/content/TOC width sliders.
- **Recent folders** — folder picker remembers the last 8 folders.

### CSV editor improvements

- Sort by column from the header menu.
- Range selection (drag / Shift+click), Ctrl+C / Ctrl+V as TSV (Excel / Google Sheets compatible).
- Sum and average of selected numbers.
- Fill handle: drag to fill a series (1, 2, 3…) or copies; Ctrl toggles mode.
- CSV size limit now 500 KB by default, adjustable 100 KB – 10 MB.

### Other changes

- Without `--port`, the server reuses the port from the previous run.
- Lock state, last port and quick-note setting are stored in `~/.friend-in-md/` — nothing is written into your notes folder except your own edits.
- New app icon.
